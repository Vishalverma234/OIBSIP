# 🌡️ Temperature Converter Website

A responsive web-based **Temperature Converter** developed as **Task 3** during my Web Development & Designing Internship at **Oasis Infobyte**.

The website allows users to convert temperature values between **Celsius, Fahrenheit, and Kelvin** with a simple and interactive interface.

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript

## ✨ Features

* Convert between Celsius, Fahrenheit, and Kelvin
* Instant conversion results
* Input validation
* Responsive design
* Clean and user-friendly interface
